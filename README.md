# anota.aqui — site

Site institucional estático do anota.aqui, publicado no GitHub Pages.

- `index.html` — página principal
- `licenca.html` — licença MIT
- `privacidade.html` — política de privacidade (LGPD)
- `assets/site.css` — sistema visual completo
- `assets/videos/` — jornada completa e episódios (MP4 1360x768, 60 fps, sem áudio) com pôsteres
- `robots.txt`, `sitemap.xml`

Os vídeos são publicados a partir de `Desktop/anota-aqui-videos` com
`python scripts/publish-videos.py` (copia os finais e os pôsteres e confere
duração, fps e ausência de áudio).

Sem build, sem dependências. Abra `index.html` ou publique a pasta como está.
